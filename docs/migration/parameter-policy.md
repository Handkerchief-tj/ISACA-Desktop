# 参数与默认值策略

## 优先级

1. 本次分析的用户覆盖值。
2. 网表 `.param` 定义。
3. 元件行中的直接数值。
4. 用户明确启用的 SLiCAP 5.2.1 默认值。
5. 未解析符号。

每个参数保存 `expression`、`numeric_value`、`source`、使用位置、是否为数值分析必需
以及采用默认值时的 SLiCAP 版本。

## 工程后缀

解析器支持 `T/G/meg/k/m/u/n/p/f/a` 以及科学计数法。大小写按 SLiCAP 的工程后缀
语义处理，例如 `1m=1e-3`；百万应写作 `meg`。

## SLiCAP 5.2.1 实际缺省值

通过最小探针网表和 `SLiCAPmodels.lib` 校验：

- 基础 R/C/L、独立源和四种受控源的缺省参数为 0。
- MOS 小信号模型默认 `gm=1m`，其余列出的电导和电容为 0。
- QV BJT 默认 `gm=40m`、`gpi=2.5k`，其余列出的参数为 0。

这些数值只是软件原型的缺省值，不代表工艺或偏置点。严格模式不会自动采用它们；
启用后必须在诊断和结果中标记 `slicap_default` 与版本号。

## 数值完整性

独立输入源的符号幅度可由传递函数归一化，因此仅用于 `V/I.value` 等激励上下文的
符号不阻止数值分析。影响网络系数的未解析参数会阻止数值、根聚类和误差评估，
但符号分析仍可保留该符号。
