# SLiCAP 兼容矩阵

| 能力 | 4.0.8 基线 | 5.2.1 新系统 | 处理方式 |
|---|---|---|---|
| `.cir` 解析和层次展平 | 已使用 | 已验证 | SFG 私有依赖集中到兼容层 |
| `makeCircuit` | 可用 | 公共入口 | FastAPI 仅通过适配器调用 |
| `doLaplace/doPZ/doMatrix/doNoise` | 可用 | 已验证 | 返回对象直接序列化，不解析 HTML |
| 项目目录/HTML 初始化 | 会产生文件 | 仍会产生文件 | 每任务独立目录 |
| 全局解析器状态 | 存在 | 存在 | 进程内锁；未来进程隔离 |
| `.slicap_sch` | 无当前集成 | 5.2.1 JSON | 内部模型双向适配，官方 CLI 测试 |
| SFG 私有接口 | 直接导入 | 名称/位置有变化 | `sfg_prototype.slicap_compat` 统一解析 |
| 默认模型值 | 旧案例可能隐式依赖 | 版本化记录 | 默认严格，必要时网表显式赋值 |

目标依赖固定为 `SLiCAP==5.2.1`。升级到后续版本时，必须先扩展兼容矩阵和测试，
不能只修改版本约束。
