# 论文算法一致性审计

本文档按论文 Fig. 12、Section III 和 Section IV 检查当前实现。结论分为“已对齐”、
“工程化补充”和“仍需完善”，避免把辅助启发式误称为论文原算法。

## 已对齐的主流程

| 论文定义 | 当前实现 | 说明 |
|---|---|---|
| Eq. (6)-(7) 性能误差 | 已实现 | 在用户频率网格上比较原始与化简传函，支持幅值、相位和复相对误差范数。累计绝对误差用于接受，候选相对误差用于排序。 |
| Eq. (9)-(10) 图复杂度 | 已实现 | 统计一阶环节、求和点、前向路径和反馈回路，并提供简化复杂度。 |
| Eq. (11)-(12) ranking/quality | 已实现 | 候选按性能误差和复杂度收益排序，每次操作在图副本上试做，可拒绝和回滚。 |
| Eq. (13)-(14) 根聚类与频段 | 已实现 | 按闭环根幅值的相对距离聚类，再以相邻根簇的几何平均值划分频段。聚类检查使用整个簇的跨度，避免相邻链式合并远端根。 |
| Fig. 12 四类操作 | 已实现框架 | 按 `VPC -> RSP -> RR -> SS` 执行；小图先完整枚举合法 `RSP/RR`，再按 Eq. (11) 排序，并在每次接受后重新分析局部图。 |
| OLR/SPR 定位 | 已实现主要路径 | 从 meta-edge/order partition 识别 OLR，从局部反馈特征式和前向路径抵消识别 SPR-P/SPR-Z。 |
| feedback observability | 已对齐主边界 | 开环极点遮蔽使用论文所述的 `|loop gain| >= 1`；下游路径“完全支配”比例显式配置。 |
| root shifting | 已对齐 | 默认不以逐根 5% 偏差否决候选。论文 Section III-E 明确允许在虚轴性能误差受控时发生根移动。 |

## demo_2 的关键对照

- 第一频段自动得到求和点极点的紧凑分组式。令 `A=Gin*gpi+Gin*gx+gpi*gx`，程序结果为 `-(Gl+go)*A / ((Cl+cmu+cx)*A + cmu*gm*(Gin+gx))`，约 `-346.01 Hz`，根位置偏差约 `3.7%`；它与当前 Fig.11(a) 图方程严格等价。论文 Eq. (21) 的约 `-354 Hz` 还使用了一层正文没有量化的近似。
- 第二频段自动恢复论文 Eq. (22)：

  ```text
  -(gm*cmu + (gx + gpi)*(cmu + cx + CL))
  / ((cmu + cpi)*(cmu + cx + CL))
  ```

  当前参数下约为 `-47.7 kHz`，而精确闭环极点约为 `-34.6 kHz`，根位置偏差约
  `36.9%`。这不是默认验收失败：该频段化简图相对原传函的最大误差约为
  `0.059 dB`、`4.19 deg`，仍满足用户指定的 `±2 dB`、`±5 deg`。
- 第三频段恢复论文 Eq. (23) 的 `gm/cmu` 零点。
- 第四频段恢复论文 Eq. (24) 的 `-gx*cmu/(cx*(cmu+cpi))` 零点，以及
  Eq. (25) 的 `-(Gin+gx)/cx` 极点。

### Table III 边界的可复现性说明

当前代码严格把 Table II 的闭环根送入 Eq. (13)-(14)，因此得到约
`3.40 kHz`、`468.6 kHz`、`98.2 MHz` 三个内部边界。论文 Table III 列出的则是
`5.79 kHz`、`549 kHz`、`98.4 MHz`。其中第三条与闭环根几何平均一致，前两条
不能由 Table II 数值直接重算得到。

这不是通过调大采样数可以消除的数值误差，而是论文公开信息中的算法输入不完整：
前两条边界似乎还受局部 open-loop/SPR 候选频率影响，但正文只明确写了先对数值根
聚类，再按 Eq. (13)-(14) 构造范围。当前实现不会为匹配 Table III 硬编码边界；在
找到作者更完整的 root-set 定义前，报告同时列出公式计算值和论文表格值，并把该项
保留为待澄清差异。

## 工程化补充，不应冒充论文定义

- 论文没有公开具体频率采样点、权重和所有范数参数；代码将它们显式配置并写入报告。
- `fallback/reconvergent` 区域只用于解释局部根；只有 strict complementary graph cut
  才允许自动执行保守的 SS 替代。
- 可选的逐根主导项视图、数值贡献阈值、符号表达式规模上限和矩阵回退用于控制计算量，它们是实现策略，
  不是论文中的新公式。
- `auto` 候选模式仅在 meta-edge 数不超过配置上限时完整枚举；大型图的数值贡献预筛选是工程化的规模保护，不是论文定义。
- 论文没有量化 downstream path “totally dominated”，默认支配比 `10` 是公开可配置的工程参数，不冒充论文经验值。
- 多回路电路没有唯一的标量 loop gain；当前实现取 Mason 闭环有效增益与相关简单回路幅值总包络的较大值，再与论文的单位增益边界比较。这能复现 C.0.a/C.0.b 的 OLR-NO 结论，但属于对论文文字描述的保守实现。
- 参数角点检查是稳健性扩展；仅在用户显式提供参数容差时启用。
- 逐根位置误差门槛是可选的 Section III-E 变体，不是默认图操作验收条件。

## 尚未完全达到论文级别的部分

1. strict complementary graph cut 与 downstream observability 的实现仍偏保守，复杂图上可能返回 fallback 或 unresolved。
2. 小图已穷举论文定义的合法 `RSP/RR` 候选；大型图仍使用局部数值贡献预筛选，因此大图搜索并非全局穷举。
3. 第一频段已完成严格等价的参数分组，但不会在没有用户参数关系或误差证据时强行变成 Eq. (21)；论文没有说明该最后一步近似的通用判据。
4. 局部 SPR 与闭环根簇的关联仍包含相对频率启发式；它只决定候选归属，不再决定图操作是否被接受。
5. 复共轭根、多重根和大型图的局部传函重构仍需更系统的联合删项与因式化策略。
6. 论文第 7 步的偏置节点预化简目前要求用户声明节点对，尚未从偏置拓扑自动识别。
7. 论文没有公开其完整实现、采样网格和全部经验参数，因此无法保证逐操作序列逐项相同；可验证目标应是最终表达式、复杂度和用户性能误差。
8. 论文 Table III 的前两条频段边界与 Table II 闭环根直接代入 Eq. (13)-(14) 的结果不一致；内部 root set 是否包含局部候选根，正文没有充分说明。

## 后续优先级

1. 以局部传函重构误差替代 SPR 候选归属中的固定频率启发式，并优先恢复 Eq. (21) 的短式。
2. 完善 strict graph cut 和根可观测传播，使更少案例依赖 fallback。
3. 为大型图增加分层候选批次与可恢复的逐步审计，在不失控的前提下逐步放宽有界搜索。
4. 将每个 `G_j^*` 的局部根表达式统一重构为可读的 `H_j(s)`，并再次用 Eq. (6)-(7) 验收。
